# Gabarito Aula 1

### Exercício Guiado

#### 1. O que é Internet?

A Internet é uma rede mundial de computadores e dispositivos conectados que permite a troca de informações entre usuários em todo o mundo.

***

#### 2. O que é Web?

A Web (World Wide Web) é um sistema de páginas e aplicações acessadas através da Internet por meio de navegadores.

***

#### 3. Qual a diferença entre Internet e Web?

A Internet é a infraestrutura que conecta dispositivos.

A Web é um serviço que utiliza essa infraestrutura para disponibilizar páginas e aplicações.

***

#### 4. O que é Web Design?

Web Design é a área responsável pelo planejamento, organização e criação visual de websites.

***

#### 5. O que significa HTML?

HTML significa HyperText Markup Language (Linguagem de Marcação de Hipertexto).

***

#### 6. O que é semântica HTML?

É a utilização de elementos que possuem significado e descrevem corretamente a função do conteúdo.

***

## Exercícios de Fixação

### Questão 1

Defina Internet.

#### Resposta

A Internet é uma rede mundial de computadores e dispositivos conectados.

***

### Questão 2

Defina Web.

#### Resposta

A Web é um sistema de páginas e aplicações acessadas pela Internet.

***

### Questão 3

Explique a diferença entre Website e Aplicação Web.

#### Resposta

Website apresenta informações.

Aplicação Web permite interação e execução de tarefas.

Exemplos:

Website:

* Blog
* Portal de notícias

Aplicação Web:

* Gmail
* Canva

***

### Questão 4

Qual é a função do HTML?

#### Resposta

Estruturar o conteúdo das páginas Web.

***

### Questão 5

Explique o conceito de semântica.

#### Resposta

Utilizar elementos que indiquem corretamente o significado do conteúdo.

***

### Questão 6

Cite três elementos semânticos.

#### Resposta

```html
<header>
<nav>
<footer>
```

Também seriam aceitos:

```html
<main>
<section>
<article>
```
